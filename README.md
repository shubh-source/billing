---

## 🚀 Quick Start (Instant Launch)

### Method 1: Instant Launch (Double Click)
- Double-click **`start.bat`** in this folder, or
- Double-click **`index.html`** to open it immediately in your browser (Chrome, Edge, Firefox, Brave). No setup or server needed!

### Method 2: Node.js Local Server
Run with the built-in zero-dependency server:
```bash
node server.js
```
Then open: **`http://localhost:3000`** in your browser.

## 🌐 Features Tailored for Website Projects

1. **1-Click Website Package Presets**:
   - 🌐 **Complete Business Website:** Responsive multi-page website, modern UI/UX, contact form.
   - 🛒 **E-Commerce Online Store:** Product catalog, shopping cart, payment gateway integration.
   - 🚀 **High-Converting Landing Page:** Speed-optimized funnel, hero CTA, lead capture forms.
   - 🔒 **Cloud Hosting, Domain & SSL (1 Year):** Fast NVMe SSD cloud hosting, domain setup, SSL certificate.
   - ⚡ **Core Web Vitals & Speed Optimization:** 90+ Google PageSpeed score, WebP compression, minification.
   - 🛡️ **Annual Website Maintenance (AMC):** Security monitoring, core updates, backups.
   - 📱 **Custom Web App / SaaS MVP:** User authentication, database, REST APIs, admin dashboard.
   - ➕ **Custom Deliverables:** Add any custom service, quantity/hours, and rate.

2. **Project & Domain Badges**:
   - Specify project title and client domain (e.g. `🌐 www.clientbrand.com`) right on the invoice header.

3. **Multi-Currency & Tax Engine**:
   - **Currencies:** INR (₹), USD ($), EUR (€), GBP (£), AED, CAD, AUD.
   - **Taxes:** CGST + SGST (18%), Inter-State IGST (18%), Flat VAT/Sales Tax, or 0% Tax.
   - **Milestone / Advance Payments:** Track advance deposits (e.g., 50% upfront) and compute the net balance due.

4. **Export & Client Sharing**:
   - 🖨️ **Print / Save as PDF:** `@media print` A4 layout with page-break protection and clean borders.
   - 💬 **Send via WhatsApp:** Formats a clean WhatsApp billing breakdown with balance due and contact info.
   - 📋 **Copy Invoice Summary:** Quick clipboard copy for emails and messages.
   - 💾 **Invoice History & Duplication:** Save past bills locally, search, reload, duplicate, or delete anytime.
   - 🎨 **5 Color Themes:** Modern Indigo, Deep Slate, Emerald Tech, Crimson Agency, and Cyan Digital.
